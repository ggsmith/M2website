Open Spotlight Search with Cmd + Spacebar, then search for Terminal. Click the Terminal app in the search results, and a terminal window should open.

- number: 2 title: Install Homebrew content: - type: html value: |

Go to the Homebrew website, then return to the terminal you opened in the previous step. Enter the install command shown on the Homebrew site; it currently looks like this:

- type: code language: bash value: '/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"' - type: html value: |

Press return to run it. Homebrew will probably ask for your password; type it and press return again. No characters will appear while you type your password, which is normal. The command may change, so always verify the current command on the Homebrew website.

- number: 3 title: Add Homebrew to PATH content: - type: html value: |

After installation, Homebrew will likely print commands for adding Homebrew to your PATH so your Mac knows where the software lives. These commands can be different for each user, so copy the commands shown in your own terminal, paste them in, and press return.

To confirm Homebrew is available, run:

- type: code language: bash value: brew help - type: html value: |

If you see help output with sections like example usage, troubleshooting, contributing, and further help, you are ready to continue.

- number: 4 title: Install Macaulay2 content: - type: html value: |

In the terminal, run the following command to install Macaulay2. This might take a few minutes.

- type: code language: bash value: brew install Macaulay2/tap/M2 - type: html value: |

If the command has changed or does not work, refer to the Macaulay2 Homebrew tap or the Macaulay2 download page.

To confirm the installation, run:

- type: code language: bash value: M2 - type: html value: |

If you see output like this, you are good to go:

- type: code language: text value: | Macaulay2, version x.xx.xx Type "help" to see useful commands i1 : helpful_links: - title: Homebrew href: https://brew.sh/ - title: Macaulay2 Homebrew tap href: https://github.com/Macaulay2/homebrew-tap - title: Macaulay2 download page href: https://mahrud.github.io/LearnM2/download/ - os: Windows id: "windows" steps: - number: 1 title: Open PowerShell as Administrator instructions: |

On Windows, Macaulay2 is easiest to install through Windows Subsystem for Linux using Ubuntu. Open the Start menu, search for PowerShell, right-click it, and choose Run as administrator.

- number: 2 title: Install WSL content: - type: html value: |

In the administrator PowerShell window, run:

- type: code language: powershell value: wsl --install - type: html value: |

Restart your computer if Windows asks you to. This command normally enables WSL and installs Ubuntu by default. If the command is unavailable or fails because WSL is missing, install the latest WSL package from Microsoft's WSL releases page, then try the command again.

- number: 3 title: Install or Launch Ubuntu content: - type: html value: |

If Ubuntu was not installed by the previous command, run this from PowerShell:

- type: code language: powershell value: wsl --install -d Ubuntu - type: html value: |

You can also install Ubuntu from the Microsoft Store by searching for Ubuntu and choosing an LTS release. Launch Ubuntu from the Start menu, wait for it to finish setting up, and create the Linux username and password it asks for.

- number: 4 title: Install Macaulay2 in Ubuntu content: - type: html value: |

These commands go in the Ubuntu terminal, not in PowerShell. Add the stable Macaulay2 Ubuntu PPA, update package lists, and install Macaulay2:

- type: code language: bash value: | sudo apt update sudo add-apt-repository ppa:macaulay2/macaulay2 sudo apt update sudo apt install macaulay2 - type: html value: |

If Ubuntu says add-apt-repository is not found, run sudo apt install software-properties-common, then repeat the PPA command. The older ppa:profzoom/macaulay2 PPA is for development builds, so use the stable PPA above unless you specifically want a development version.

- number: 5 title: Confirm the Windows Setup content: - type: html value: |

Still inside Ubuntu, run:

- type: code language: bash value: M2 - type: html value: |

If you see the Macaulay2 welcome text and an i1 : prompt, the installation worked. Type exit to leave Macaulay2, and type exit again to close the Ubuntu shell.

On Linux, you do not need WSL. Open your normal terminal application and use the commands for your distribution. Ubuntu and Debian-based systems use apt, while Fedora and similar systems use dnf.

- number: 2 title: Install on Ubuntu content: - type: html value: |

For supported Ubuntu releases, the Macaulay2 project recommends adding the stable Macaulay2 PPA and installing with apt:

- type: code language: bash value: | sudo apt update sudo add-apt-repository ppa:macaulay2/macaulay2 sudo apt update sudo apt install macaulay2 - type: html value: |

If add-apt-repository is missing, install it with sudo apt install software-properties-common, then rerun the PPA command.

- number: 3 title: Install on Debian content: - type: html value: |

On Debian, Macaulay2 is available through apt, though stable Debian may provide an older version. Start with:

- type: code language: bash value: | sudo apt update sudo apt install macaulay2 - type: html value: |

For newer packages on Debian stable, follow the Debian-specific repository instructions on the Macaulay2 Linux installation wiki, since the repository file depends on your Debian release.

- number: 4 title: Install on Fedora or RHEL-compatible Linux content: - type: html value: |

Fedora users can install Macaulay2 with dnf:

- type: code language: bash value: sudo dnf install Macaulay2 - type: html value: |

For the latest Fedora packages, or for Red Hat Enterprise Linux and compatible distributions such as Rocky Linux or AlmaLinux, use the repository instructions from the Macaulay2 Linux installation wiki before running the dnf install command.

- number: 5 title: Confirm the Linux Setup content: - type: html value: |

After installation, start Macaulay2 from your Linux terminal:

- type: code language: bash value: M2 - type: html value: |

If you see the Macaulay2 welcome text and an i1 : prompt, the installation worked. Type exit to leave Macaulay2.

helpful_links: - title: Macaulay2 Linux installation wiki href: https://github.com/Macaulay2/M2/wiki/Installing-Macaulay2-in-Linux - title: Macaulay2 Ubuntu packages href: https://macaulay2.com/Downloads/GNU-Linux/Ubuntu/ - title: Macaulay2 GitHub repository href: https://github.com/Macaulay2/M2 codespace_steps: - number: 1 title: Open the Macaulay2 repository content: - type: html value: |

You need a free GitHub account and should be logged into GitHub before starting. Open the official Macaulay2 source repository in your browser.

- number: 2 title: Create the Codespace content: - type: html value: |

Near the top-right of the file list, click the green <> Code button. In the dropdown, switch to the Codespaces tab, then click Create codespace on stable (or the latest stable version of Macaulay 2) or the + icon.

If you plan to modify Macaulay2 source code and keep your changes permanently, fork the repository first and create the Codespace from your fork.

- number: 3 title: Wait for initialization content: - type: html value: |

A new browser tab will open with a web-based Visual Studio Code window. Wait for the container setup to finish; this can take a few minutes because the environment downloads dependencies and prepares a Linux container.

You are ready when the terminal stops printing setup logs and shows a normal prompt such as @codespace:/workspaces/M2$.

- number: 4 title: Run the Macaulay2 shell content: - type: html value: |

Open the integrated terminal if it is not already visible by choosing Terminal > New Terminal. You can also use Ctrl + ` on Windows or Linux, or Cmd + ` on Mac.

Run:

- type: code language: bash value: M2 - type: html value: |

You should see the Macaulay2 welcome message and an interactive prompt like this:

- type: code language: macaulay2 value: | i1 : - type: html value: |

If M2 returns command not found, the latest source checkout may need to be built first. Run make in the repository terminal, wait for it to finish, then try M2 again.

- number: 5 title: Install the VS Code extension content: - type: html value: |

For a better editing experience, install the Macaulay2 VS Code extension inside the Codespace. Click the Extensions icon in the left sidebar, search for Macaulay2, and click Install.

The extension adds useful editor features such as syntax highlighting, auto-completion, and tools for sending code from a file to an interactive Macaulay2 session.

- number: 6 title: Write your first script content: - type: html value: |

In the file explorer, click the New File icon and create a file named hello.m2. Add a small Macaulay2 example:

- type: code language: macaulay2 value: | R = QQ[x, y, z] f = (x+y+z)^3 - type: html value: |

You can run the file using the extension, or from the active M2 prompt with:

- type: code language: macaulay2 value: load "hello.m2" - type: html value: |

GitHub Codespaces saves your environment automatically. To return later, go to github.com/codespaces and reopen your active Macaulay2 Codespace. Note that free GitHub accounts receive 60 free hours of active codespaces per month. Once you reach that limit, you will be billed according to GitHub's codespace pricing.
